# KRATOS PLAYER — documentos legales (direcciones antiguas)

Páginas legales de la aplicación **KRATOS PLAYER**, un reproductor multimedia para Smart TV.

**Estas direcciones se mantienen vivas a propósito**: los televisores que ya tienen la aplicación
instalada las llevan grabadas dentro. Las direcciones nuevas, y las que van en la ficha de la tienda,
son las de <https://osmaredriel-cell.github.io/kratosplayer/>.

- [Política de privacidad / Privacy Policy](https://osmaredriel-cell.github.io/vistaplayer/privacy.html)
- [Términos de uso / Terms of Use](https://osmaredriel-cell.github.io/vistaplayer/terms.html)
- [Reporte de infracción / DMCA](https://osmaredriel-cell.github.io/vistaplayer/dmca.html)

La aplicación es únicamente un reproductor: no incluye ni distribuye canales, listas,
suscripciones ni contenido. El usuario aporta su propio servicio.
